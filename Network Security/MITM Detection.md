Man-in-the-middle attack covers the cyberattack where an attacker intercepts and potentially alerts communication between two parties, like user-service without their knowledge!
This can lead to many risks, including sensitive data exposure (like credentials, credit card information) or allowing to inject malicious content.

![[Pasted image 20260312091218.png]]




**How it works?**:

1. ==Interception==:
	The attacker inserts themselves into a communication stream or exploiting weaknesses in network protocols  like ARP-, DNS- or IP-spoofing.

2. ==Manipulation==:
	Identify or access the communication, decrypting encoded data, or injecting harmful content, like altered website logins or fake login forms 


**Common Types**:

- ==Packet Sniffing==:
	Capturing unencrypted data packet over a network, often on open Wi-Fi
- ==Session Hijacking==:
	Stealing and using session tokens to impersonate users
- ==SSL Stripping==:
	Downgrading HTTPS connections to insecure HTTP to see & steal transferred data
- ==DNS spoofing==:
	Replaces IP addresses to domain names 
- ==IP spoofing==:
	Crafting malicious IP packets that appear to come from trusted sources
- ==Rogue Wi-Fi AP==:
	Creating fake networks to intercept users traffic
