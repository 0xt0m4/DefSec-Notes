

Popular **search operators**:

- `"exact phrase"`: double quotes indicate your're looking for pages with the exact word/phrase
- `site:asd.com`: lets you specify the domain
- `-`: allows you to omit search results
- `filetype:pdf`: finds files instead of web pages


---


Specialized **Search engines**:
   
- [Shodan](https://www.shodan.io/): allows to search for specific server version, routers, webcams and IoI devices. (can look for websites using a specific version, which can allow a CVE)
- [Censys](https://search.censys.io/): focuses on internet-connected hosts, websites, certs and other assets. (for domain enumeration, auditing open ports/services: [Censys Introductory Use Cases](https://docs.censys.com/docs/ls-introductory-use-cases#/))
- [Virustotal](https://virustotal.com/): For file, URL, IP, domain or hash lookup, to see if its malicious
- [Have I Been Pwned](https://haveibeenpwned.com/): tells you if the email/password has been compromised
