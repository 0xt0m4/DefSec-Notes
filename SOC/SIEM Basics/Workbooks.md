
Workbooks set the workflow of the steps required to investigate and respond to different kind of actions.

- Identity:
	refers to person's data. E.g if the user _G.Baker_ logs into a database, you must check his identity, to see who is he. These information like Full name, role, location, email etc.

- Inventory
	Refers to system information, like hostnames, IP addresses, OS-es, or purpose
	e.g if G.Baker used the HQ-ADDC-01 server, you check the inventory 


- **Enrichment:**
	The process of threat Intelligence, and identifying inventory to get info about the affected user
