# Hash Values (Trivial)


A **hash** is a numeric value of a fixed length, that used to uniquely identify data.

Some **common algorithms** are:
- MD5: 
	cryptographically not secure, cause of hash collision and other attacks
- SHA-1 (Secure Hash Algorithm):
	It's susceptible to brute-force attacks
- SHA-2
	SHA-2 has many variants, and arguably the most common is **SHA-256**, which has 256-bits as a 64 digit HEXA number


Many online tools can be used to do hash lookups, like **Virustotal** or **Metadefender Cloud - OPSWAT**. However, if the file has been modified even a bit, the has value will be different

# Host Artifacts (Annoying)


_From this layer, the attacker will feel a little more annoyed and frustrated, if you can detect the attack._


**Host Artifacts** are the traces of observables that attackers leave on the system, e.g registry values, process executions, attack patterns or IOCs, file dropped by malicious application or webapp, or anything exclusive.

Or unusual anomaly/behavior


# Network Artifacts (Annoying)


It can e a user-agent string, C2 information or URI patterns followed by the HTTP POST request. 

These can be usually detected in **wireshark**, or through **IDS**


Some unique user-agent string can make you think of different type of attacks. 

- First, if the user is trying with a completely different browser he usually uses, and gets many incorrect passwords, that's suspicious
- Or if a user-agent is known for it's malicious activity. E.g if you see `Mozilla/4.0(compatible;MSIE7.0;WindowsNT6.1;Trident/4.0;SLCC2;.NETCLR2.0.50727; .NETCLR3.5.30729;.NETCLR3.0.30729;MediaCenterPC6.0;.NET4.0C;.NET4.0E)` that's the most common user-agent strings found for the _Emotet Downloader Trojan_

# Tools (Challenging)


Any custom code written by the attackers, like creating a malicious macro documents for spearphising, a backdoor that can be used to establish a C2 connection, any custom .EXE or .DLL, files, payload and password crackers are tools. 

To capture these, several platforms and methods can be used
For instance:

Antivirus signatures, detection rules and YARA rules:

- For **YARA** results, **samples** and malicious feeds, check out 
	[MalwareBazaar](https://bazaar.abuse.ch/) and
	[Malshare](https://malshare.com/)


- For **detection rules**
	[SOC Prime Threat Detection Marketplace](https://tdm.socprime.com/) is a great platform
	Here you can find professional's detection rules for any kind of threats, including latest CVE's.

- For **signature**-based findings
	An effective way is **fuzzy hashing**. This can help you perform similarity analysis. For this, you can use [SSDeep](https://ssdeep-project.github.io/ssdeep/index.html) but it's also implemented into virustotal

The apex of the Pyramid of Pain is nothing else, but TTPs!

TTPs stands for **Tactics, Techniques and Prcedures**! This includes the whole [MITRE ATT&CK Matrix](https://attack.mitre.org/)
