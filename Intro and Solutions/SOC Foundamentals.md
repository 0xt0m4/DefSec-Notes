
# Main Purpose

The purpose of the Security Operations Center is basically the **Detection** and **Response**!

The three pillars of this are:

1. People (SOC team helps the Security Solution to identify harmful activities, and enable response)![[Pasted image 20260202164356.png]]
2. Process (The process itself of handling incidents (see [[SOC Foundamentals#2. Alert Triangle]]))
3. Technology (SIEM, EDR, Firewall, IDS/IPS, XDR etc.)


## 2. Alert Triangle

Or 5Ws are:

![[Pasted image 20260202164708.png]]


Example:

**Alert:** Malware Detected on Host: `GEORGE PC`

| 5 Ws   | Answers                                                                                                                                                                                                                       |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| What?  | A malicious file was detected on one of the hosts inside the organization’s network.                                                                                                                                          |
| When?  | The file was detected at 13:20 on June 5, 2024.                                                                                                                                                                               |
| Where? | The file was detected in the directory of the host: "GEORGE PC".                                                                                                                                                              |
| Who?   | The file was detected for the user George.                                                                                                                                                                                    |
| Why?   | After the investigation, it was found that the file was downloaded from a pirated software-selling website. The investigation with the user revealed that they downloaded the file as they wanted to use a software for free. |
