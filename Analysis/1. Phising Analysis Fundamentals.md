# Delivery

To send emails, there are some common **protocols** being used when you send an email.

There are 3 specific protocols involved regarding to emailing, that are also having a secured version (and secured ones works on different ports):

- `SMTP`:
	Simple Mail Transfer Protocol handles the sending of emails
- `POP3`:
	Post Office Protocol transfers the email between a client and a mail server
- `IMAP`:
	Internet Message Access Protocol transfers the email between a client and a mail server


POP3 and IMAP almost are doing the same job, but there are differences:

| POP3                                   | IMAP                                                                   |
| -------------------------------------- | ---------------------------------------------------------------------- |
| Emails are stored on a single device   | Stored on a server and can be downloaded to multiple devices           |
| Emails accessable from a single device | Emails can be downloaded to any device from the server (can be synced) |

# Components


The **format** of the email (IMF, or Internet Message Format) can be broken down into the following components:

1. `From`
	The sender's email address
2. `Subject`
	The email's subject line
3. `Date`
	Date of the email was sent
4. `To`
	The recipient's email address

During an email analysis, you want to view the message **as raw** (usually an option at the three dots)
![[Pasted image 20251119125457.png]]


Which has some interesting fields, such as:

- `X-Originating-IP/X-header`
	The IP address of the email was sent from 
- `SMTP.mailfrom/header.from`
	The domain the email was sent from
- `Reply-To/Return-Path`
	The email address's IP where the reply will be sent

# Types of Phishing


- `Spam`:
	junk email sent to a large number of recipients, also known as MalSpam
- `Phishing`: 
	emails sent to a target providing sensitive individuals, purporting to be a trusted entity
- `Speak phishing`:
	targeting a specific individual(s) or organization seeking sensitive information
- `Whaling`:
	Like spear phishing, but it's targeted to C-Level high-position individuals, like CEO, CFO etc.
- `Smishing`:
	targeting mobile users with specially crafted text messages
- `Vishing`:
	similar to smishing, but instead of text messages, usually it's done via voice calls


Some characteristics phishing emails have in common:

- The **Sender email name/address** will masquerade as a trusted entity (can be done via email spoofing e.g)
- The email was written with a **sense of urgency**
- The body's HTML is poorly formatted
- The body's HTML is designed to match a trusted entity 
- The body uses generic content (E.g Dear Sir/Madame)
- **Hyperlinks** or **URL shortened** services to hide the true origin, or **punycode attacks**
- A malicious attachment masquerading as a legitimate document
